# System Color 4.0 beta — Modelo 3 Gamer

Aplicativo Android Kotlin (Android 11+) com interface escura neon, títulos em fonte nativa sans-serif-condensed bold, perfis Jogos/Vídeos/Uso Noturno, seis tonalidades e controle de intensidade. Menu flutuante desativado por padrão.

## Compilar sem Android Studio
Envie todo o conteúdo desta pasta para um repositório GitHub. Em **Actions → Build Android APK → Run workflow**, baixe o artefato `SystemColor-debug-apk` após uma compilação bem-sucedida.

## Permissões
Ative **Exibir sobre outros apps** nas configurações Android. O serviço de primeiro plano mantém a camada de cor enquanto ativado. O app não modifica pixels de outros aplicativos, não fornece HDR ou saturação real, e algumas telas protegidas podem ocultar a camada.
